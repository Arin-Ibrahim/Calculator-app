# Calculator-app
3 small programs each in different engineering levels. 

Version 1- Over engineered: 
this project was made as an assignment, to make a simple calculation terminal app as over engineered as possible,
so the approach was to create as many classes as possible for every function.

Verstion 2- Under engineered: 
This was an assingment to create and make a simple java calculation terminal app,
as underegineered as possible hense why everything is within the main, and in one print line

Version 3- Well engineered:
This version has a more balanced software design using OOP principles and a cleaner class structure.
Responsibilities are separated more effectively for readability, maintainability, and scalability.

Built as part of a coursework focused on practical software architecture and clean class design.
